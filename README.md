## Gokaran Shukla

Postdoctoral Research Fellow at **KAUST**, working in computational condensed-matter physics and materials science:
spin–orbit and orbital torques, orbitronics, magnetism, strongly correlated electrons and spin-dependent transport,
from first principles (DFT, Wannier functions, Green's functions).

[Website](https://gokaran-shukla.github.io) · [Google Scholar](https://scholar.google.com/citations?user=ChR9ktYAAAAJ)

### Software

| | |
|---|---|
| **[magex](https://github.com/Gokaran-Shukla/magex)** | Magnetic exchange tensors, DMI, single-ion and magnetocrystalline anisotropy, Bruno-renormalised and ligand-downfolded couplings, finite-angle (Lloyd) pair energies and spin waves from Wannier90 Hamiltonians. Rotationally invariant Green's-function method, MPI-parallel. |
| **[risb-wannier](https://github.com/Gokaran-Shukla/risb-wannier)** | Rotationally invariant slave-boson (RISB) / multi-orbital Gutzwiller solver on Wannier90 Hamiltonians, with Kanamori/Slater interactions, symmetry-adapted parameters, approximate charge self-consistency and multi-core parallelism. |
| **[ComRISB (modernised)](https://github.com/Gokaran-Shukla/ComRISB/tree/modernize)** | The comscope DFT+RISB code updated for Python 3.13, NumPy 2, h5py 3, gfortran 13 and Wannier90 3.1, with fixes to MPI charge self-consistency, U-scan continuation and band plotting. |
